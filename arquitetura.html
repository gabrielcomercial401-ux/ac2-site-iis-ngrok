Papel de cada parte

Máquina virtual (VM)

Um computador simulado dentro do computador real. Ela isola o servidor: tem memória, processador e disco próprios e pode ser criada, desligada ou apagada sem afetar a máquina física.

IIS

O servidor web do Windows. Ele escuta a porta 80, recebe as requisições HTTP e entrega os arquivos da pasta C:\inetpub\wwwroot\projeto (HTML, CSS, JS e imagens).

ngrok

A VM não tem IP público. O agente do ngrok abre uma conexão de saída até a nuvem do ngrok, que devolve uma URL HTTPS pública e encaminha cada acesso pelo túnel até o IIS.

QR Code

Só uma forma prática de levar a URL pública para o celular. Se o ngrok for reiniciado, a URL muda e o QR Code precisa ser gerado de novo.

Como o acesso externo chega ao servidor

1

Usuário externo

Abre a URL pública HTTPS no celular (ou lê o QR Code).

2

Nuvem do ngrok

Recebe a requisição e encaminha pelo túnel até o agente que roda na VM.

3

IIS na VM

O agente entrega a requisição em localhost:80 e o IIS responde com os arquivos do site.

Porta do IIS = porta do ngrok

Configuração padrão

IIS na porta 80

http://localhost/projeto/
ngrok http 80

Configuração alternativa

IIS na porta 8080

http://localhost:8080/projeto/
ngrok http 8080

Erro 404 indica endereço, pasta ou porta incorreta. Teste sempre em http://localhost/projeto/ antes de ligar o ngrok.
