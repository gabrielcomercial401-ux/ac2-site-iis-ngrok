Hospedagem de site em máquina virtual

Este site está rodando em uma máquina virtual com Windows Server 2022, publicado pelo IIS e liberado para a internet pelo ngrok. Se você está vendo esta página no celular, o caminho inteiro funcionou.

Ver de onde estou acessando Como funciona

Etapas da atividade

1

Máquina virtual

Windows Server 2022 rodando no Hyper-V ou VirtualBox, com 4 GB de RAM, 2 processadores e 40 GB de disco.

2

Site no IIS

Os arquivos ficam em C:\inetpub\wwwroot\projeto e abrem em http://localhost/projeto/.

3

Acesso público

O comando ngrok http 80 cria uma URL HTTPS pública que encaminha para o IIS.

4

QR Code

A mesma URL pública vira um QR Code para abrir o site no celular com dados móveis.

Tecnologias

HTML, CSS e JavaScript

Site 100% estático: sem back-end, sem API e sem banco de dados.

Windows Server 2022

Sistema operacional do servidor, instalado dentro da VM.

IIS

Internet Information Services, o servidor web da Microsoft, escutando na porta 80.

ngrok

Cria um túnel seguro e temporário da internet até a porta do IIS.
